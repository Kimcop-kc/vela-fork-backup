# 本地拆书知识库

拆书 = 把一本参考小说按章拆开，逐章写进**本地**知识库（LanceDB），供检索、文风分析与后续写作引用。

## 一、入口

左侧活动栏新增「拆书」视图：

- 侧栏：导入参考小说、书列表（章节数 / 字数）、移除、当前选中书。
- 正文区：本书信息（来源文件、是否已向量化）、**本书范围内检索**、章节清单。

导入后自动选中该书，并广播 `REFRESH_RESOURCE`，知识库面板同步看到新入库的章节。

## 二、拆章规则

与「导入小说」共用同一套规则（`electron/chapter-splitting.ts`，两处不会再漂移）：

1. 中文标准格式：`第X章 标题` / `第X章：标题`
2. 英文标准格式：`Chapter X: Title`
3. Markdown 标题：`# 第X章 标题` / `## Chapter X`
4. 一个都没命中 → 整个文件视为一章

多文件导入时按文件名自然排序，再按章号去重排序并重新连续编号。

## 三、入库与存储

- 每章一个知识库文档：`fileName = "<书名> · 第N章 <标题>"`，`chapterNumber` / `chapterTitle` 写入 chunk 元数据（供范围检索）。
- 有 Embedding 模型 → 生成向量（混合检索）；没有 → 退化为纯全文检索，功能可用。
- 拆书档案写入 `<项目>/.vela/books/<bookId>.json`，记录书名、来源路径、导入时间、章节数、字数、是否向量化、每章的 `docId` 与 `fileName`。
- 重复导入同一本书会先清掉同名的旧章节文档，结果幂等。

## 四、本书内检索

检索仍走知识库通道（`kb:search`），结果按 `<书名> · ` 前缀过滤，即为「本书范围内」的命中，无需额外的索引层。

## 五、移除

移除一本拆书 = 删除档案 JSON + 逐章清理知识库文档，并回报清理了多少章。
